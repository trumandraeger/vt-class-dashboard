# VT Grade Data

A data science project focused on collecting, processing, and visualizing historical course grade distributions at **Virginia Tech**.  
The goal of this project is to provide students with an intuitive way to analyze trends across departments, instructors, and semesters, while also demonstrating skills in **data wrangling, visualization, and interactive dashboard development**.

---

## Overview
- **Data Engineering:** Scraped raw grade distribution reports and transformed them into structured CSV datasets.  
- **Data Analysis:** Used Pandas to clean, merge, and aggregate course-level data for exploratory analysis.  
- **Visualization:** Built interactive visualizations with Altair to highlight GPA distributions, grade breakdowns, and comparative trends.  
- **Dashboard Development:** Designed a Streamlit application to make data exploration accessible through a simple web interface.  

---

## Technical Stack
- **Languages & Libraries:** Python, Pandas, NumPy, Altair, Streamlit, BeautifulSoup, Requests  
- **Data Formats:** CSV, JSON  
- **Version Control:** Git & GitHub
